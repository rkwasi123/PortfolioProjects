# 🌍 COVID-19 Data Analysis Portfolio Project
This portfolio project showcases various stages of data analysis using real-world COVID-19 datasets. It includes data cleaning, SQL-based exploration, and data visualization through Tableau. This project is ideal for demonstrating end-to-end skills in data analytics.

## 📁 Project Files Overview
1. COVID Portfolio Project - Data Exploration.sql
Purpose: SQL script for exploratory data analysis (EDA) on COVID-19 datasets.

### Contents:

Queries for calculating infection rates, death rates, and vaccination trends.

Time-series breakdowns and country-level comparisons.

2. CovidDeaths.xlsx & CovidVaccinations.xlsx
Source: Our World in Data COVID-19 datasets.

### Description:

CovidDeaths.xlsx: Includes daily COVID-related deaths per country.

CovidVaccinations.xlsx: Contains vaccination rollout data by country.

Usage: Used as input data for SQL queries and Tableau dashboards.

3. Data Cleaning Portfolio Project Queries.sql
Purpose: SQL script demonstrating data cleaning techniques.

### Highlights:

Handling missing values.

Standardizing country names.

Removing duplicates and irrelevant columns.

4. Tableau Joins File.xlsx
Purpose: Merged dataset used for building Tableau dashboards.

Details: Combines cleaned death and vaccination data using country and date as join keys.

5. Tableau Portfolio Project SQL Queries.sql
Purpose: SQL queries specifically crafted for Tableau visualizations.

### Contents:

Aggregated tables.

Pre-processed insights ready for visual representation in Tableau.

📊 Visualizations
The Tableau dashboards built from this analysis include:

Global infection and death trends over time.

Country-wise vaccination progress.

Death rates vs vaccination rates correlation.

Interactive filters for regions and timelines.
